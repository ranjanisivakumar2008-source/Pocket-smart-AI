# PocketSmart AI

## Your Smart Budget & Recommendation Assistant

## Project Overview

**PocketSmart AI** is a Generative AI-powered budget and recommendation assistant designed to help users plan their expenses and receive personalized recommendations based on their **budget, preferences, and requirements**.

The project uses **Google Gemini 1.5 Flash Pro** to understand user inputs and generate suitable recommendations for different everyday planning needs.

PocketSmart AI focuses on three main areas: **Home Interior Planning, Party Planning, and Jewelry Recommendations**.

## Main Modules

### Home Interior Budget Planner

The Home Interior Planner helps users plan their home interior according to their budget. Users can provide room details, required items, quantities, and preferences.

The system provides recommendations for **furniture, lighting, decoration, ceiling fans, dining tables, and other interior requirements**.

### Party Budget Planner

The Party Planner helps users organize events based on their budget and guest count. Users can enter the event type, venue details, and other requirements.

The system provides suggestions for **food, catering, decoration, entertainment, venues, and accommodation**.

### Jewelry Budget Planner

The Jewelry Planner provides personalized jewelry suggestions based on the user's **budget, occasion, and style preferences**.

Users can optionally upload an outfit image so that the AI can consider the outfit's **color and style** while generating recommendations.

## How It Works

1. The user selects a planner category.
2. The user enters their **budget and requirements**.
3. FastAPI receives and processes the input.
4. The information is sent to the Gemini AI layer.
5. Gemini analyzes the user's preferences and requirements.
6. The system generates personalized recommendations.
7. The recommendations are displayed through the web interface.
8. Previous recommendations can be accessed through the history feature.
